# Logo assets

Place the Tip Top Welding logo here before launch.

| File | Purpose |
|------|---------|
| `logo.png` | **Primary header logo** — place at `public/images/logo/logo.png` |

The site automatically attempts to load this file. If it is missing or fails to load, the header falls back to text branding:

- **Tip Top Welding LLC**
- Mobile Welding & Custom Fabrication

## Recommendations

- Transparent PNG or SVG, at least 200px wide
- Design for both dark and light site themes (dark chrome header area + light mode nav)
- Black, chrome, and blue brand colors match the site hero

Logo config: `src/config/brand.ts` → `BRAND.logo`
